MIRA / ABCDE LTD. SYNTHETIC DATASET

Purpose
-------
This package is a synthetic replacement dataset created because the actual ABCDE Ltd.
course dataset files were not available in the provided materials.

The assignment materials establish that Mira should use:
- a project description text file
- a 6-month project timeline
- a risk matrix
- a 25-task Kanban board
- one deliberately Blocked task, T024

This package follows those structural requirements.

Files
-----
1. project_description.txt
2. timeline.csv
3. risk_matrix.csv
4. kanban_board.csv

Important
---------
Do NOT claim this is the official course dataset. If your instructor provides official
ABCDE files later, replace these files with the official versions and keep the same
workflow structure.

The n8n Mira workflow can use these files as grounding sources.
